싹둑 개인정보처리방침

시행일: 2026년 10월 23일

‘싹둑’(이하 “앱”)은 구독 결제일과 무료체험 종료를 관리하는 앱입니다. 앱은 회원가입이 없으며, 사용자가 입력한 구독 정보를 개발자 서버로 전송하지 않습니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 기기에만 저장되는 정보

사용자가 직접 입력한 아래 정보는 사용자의 기기 안에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

  • 구독 서비스 이름, 요금제, 결제 금액, 결제일, 무료체험 종료일, 결제 수단 메모
  • 공유 정산을 위해 입력한 멤버 이름(별명)과 입금 여부, 정산 받을 계좌 정보
  • 사용 빈도 체크 기록, 해지 기록, 앱 설정

이 정보는 앱을 삭제하거나 앱 안의 ‘모든 데이터 초기화’를 실행하면 즉시 삭제됩니다. 개발자는 이 정보에 접근할 수 없으므로 복구해 드릴 수 없습니다. 기기 변경 시에는 앱의 ‘백업 파일 내보내기’를 이용해 주세요. 내보낸 백업 파일의 보관 책임은 사용자에게 있습니다.

2. 광고 (Google AdMob)

앱은 무료로 제공되며, 비용 충당을 위해 Google LLC의 광고 서비스 AdMob을 사용합니다. 광고 제공과 성과 측정을 위해 Google이 아래 정보를 수집·처리할 수 있습니다.

수집 주체Google LLC (AdMob)
수집 항목광고 ID(Android 광고 ID, iOS IDFA), IP 주소, 기기 모델·운영체제 정보, 앱 내 광고 노출·클릭 기록, 대략적인 위치(IP 기반)
목적광고 게재, 맞춤형 광고, 광고 성과 측정, 부정 클릭 방지
보유 기간Google의 정책에 따름

사용자가 입력한 구독 정보(1항)는 광고에 사용되거나 Google에 전달되지 않습니다.

자세한 내용은 Google 개인정보처리방침 및 Google이 파트너 앱의 정보를 사용하는 방식을 참고해 주세요.

맞춤형 광고 거부 방법

  • Android: 설정 → Google → 광고 → 광고 ID 삭제(또는 맞춤 광고 선택 해제)
  • iOS: 설정 → 개인정보 보호 및 보안 → 추적 → ‘싹둑’ 끄기

유럽경제지역(EEA)·영국 등 동의가 필요한 지역에서는 앱 실행 시 Google의 동의 화면이 표시되며, 동의 여부에 따라 맞춤형 또는 비맞춤형 광고가 표시됩니다.

3. 알림

결제일·무료체험 종료·정산 알림은 기기 안에서 예약되는 로컬 알림입니다. 알림 내용은 외부 서버를 거치지 않습니다. 알림 권한은 기기 설정에서 언제든 끌 수 있습니다.

4. 홈 화면 위젯

위젯에 표시할 다가오는 결제 정보는 기기 안의 앱 저장 공간에만 저장되며 외부로 전송되지 않습니다.

5. 공유 기능

정산 메시지 보내기, 백업 파일 내보내기 등은 사용자가 직접 선택한 앱(예: 메신저, 파일 앱)으로만 전달됩니다. 이후 해당 앱에서의 처리는 그 앱의 방침을 따릅니다.

6. 외부 링크

앱의 ‘해지 페이지 열기’ 등은 각 서비스의 공식 웹사이트로 연결됩니다. 연결된 사이트의 개인정보 처리는 해당 사이트의 방침을 따릅니다.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 이용자의 권리

기기에 저장된 정보는 사용자가 앱에서 직접 조회·수정·삭제할 수 있습니다. 광고 관련 정보는 2항의 방법으로 맞춤형 광고를 거부하거나 광고 ID를 재설정할 수 있습니다.
